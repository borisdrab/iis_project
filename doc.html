Inštalácia

Softvérové požiadavky

  • PHP: verzia 8.4 alebo vyššia (s povolenými rozšíreniami pdo, pdo_pgsql, zip, mbstring, openssl, tokenizer, xml, ctype)
  • Správca PHP balíčkov: Composer 2.x
  • Node.js a npm: Node.js verzie 22+ a npm (na zostavenie frontendových assetov cez Vite)
  • Databázový server: PostgreSQL 18 (kompatibilný s PostgreSQL 16+)
  • Použité frameworky a knižnice: Laravel 13, Inertia.js, React 19, Tailwind CSS, Vite (alternatívne je možné aplikáciu spustiť priamo v kontajneri pomocou priloženého Dockerfile)

Lokálna inštalácia a konfigurácia

  1. Rozbaľte odovzdaný archív. Zdrojové kódy webovej aplikácie sa nachádzajú v priečinku information_system/ a databázové skripty v priečinku database/.
  2. Prejdite do adresára aplikácie a nainštalujte závislosti: 
    cd information_system
composer install --optimize-autoloader
npm install && npm run build
  3. Skopírujte konfiguračný súbor .env.example na .env a vygenerujte aplikačný kľúč: 
    cp .env.example .env
php artisan key:generate
  4. V súbore .env nastavte pripojenie k PostgreSQL databáze a URL aplikácie: 
    APP_ENV=production
APP_URL=https://iis-project-ek26.onrender.com

DB_CONNECTION=pgsql
DB_HOST=<adresa_databazoveho_servera>
DB_PORT=5432
DB_DATABASE=<nazov_databazy>
DB_USERNAME=<pouzivatel>
DB_PASSWORD=<heslo>
  5. Nastavte práva na zápis do adresárov storage/ a bootstrap/cache/ (na Linuxe chmod -R 775 storage bootstrap/cache).

Inicializácia databázy

Databázová schéma a ukážkové dáta sú uložené v priečinku database/. Z koreňového adresára rozbaleného archívu vykonajte inicializáciu spustením skriptov v nasledujúcom poradí cez nástroj psql (alebo v grafickom klientovi ako DBeaver/DataGrip):

psql -h <host> -U <pouzivatel> -d <databaza> -f database/schema.sql
psql -h <host> -U <pouzivatel> -d <databaza> -f database/data.sql

Skript schema.sql vytvorí všetky tabuľky, primárne a cudzie kľúče aj integritné obmedzenia. Skript data.sql naplní databázu testovacími používateľmi všetkých rolí, miestami, kategóriami a udalosťami a zosynchronizuje sekvencie identifikátorov.

Nasadenie na produkčný server

Produkčná verzia aplikácie beží na cloudovej platforme Render.com (región Frankfurt) ako Docker kontajner postavený zo súboru information_system/Dockerfile (obraz php:8.4-cli s Node.js 22), ktorý je prepojený so spravovanou inštanciou PostgreSQL 18. Pri spustení kontajnera sa cachuje konfigurácia aj routy (php artisan config:cache, php artisan route:cache) a spúšťa sa vstavaný HTTP server na pridelenom porte. Na školskom serveri eva.fit.vutbr.cz (~/WWW/IIS/index.html) je umiestnená presmerovacia stránka odkazujúca na živú aplikáciu.

Známé problémy

Kvôli dočasnému súborovému systému bezplatného hostingu Render.com sa dynamicky nahraté fotografie pri uspaní alebo reštarte kontajnera resetujú.
