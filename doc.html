Implementace

Aplikácia je napísaná v Laravel (PHP) s frontendom v Reacte cez Inertia.js. Routy sú v routes/web.php, logika v app/Http/Controllers/. Prístup podľa rolí zabezpečuje middleware CheckRole (administrátor je zároveň moderátor aj používateľ).

Inštalácia

Softvérové požiadavky

  • PHP: verzia 8.4 alebo vyššia (s povolenými rozšíreniami pdo, pdo_pgsql, zip, mbstring, openssl, tokenizer, xml, ctype)
  • Správca PHP balíčkov: Composer 2.x
  • Node.js a npm: Node.js verzie 22+ a npm
  • Databázový server: PostgreSQL 18
  • Použité frameworky a knižnice: Laravel 13, Inertia.js, React 19, Tailwind CSS, Vite

Lokálna inštalácia a konfigurácia

  1. Rozbaľte odovzdaný archív. Zdrojové kódy webovej aplikácie sa nachádzajú v priečinku information_system/ a databázové skripty v priečinku database/.
  2. Vytvorte a inicializujte databázu podľa sekcie Inicializácia databázy nižšie (PostgreSQL server musí bežať).
  3. Prejdite do adresára aplikácie a nainštalujte závislosti: 
    cd information_system
composer install --optimize-autoloader
npm install && npm run build
  4. Skopírujte konfiguračný súbor .env.example na .env a vygenerujte aplikačný kľúč: 
    cp .env.example .env
php artisan key:generate
  5. V súbore .env nastavte pripojenie k PostgreSQL databáze a URL aplikácie: 
    APP_ENV=local
APP_URL=http://localhost:8000

DB_CONNECTION=pgsql
DB_HOST=127.0.0.1
DB_PORT=5432
DB_DATABASE=iis
DB_USERNAME=iis
DB_PASSWORD=<heslo>
    Pri lokálnom spustení nastavte APP_ENV=local. Na produkčnom serveri (Render) je nastavené APP_ENV=production, kedy aplikácia vynucuje HTTPS, ktoré lokálny server php artisan serve nepodporuje.
  6. Nastavte práva na zápis do adresárov storage/ a bootstrap/cache/ a vytvorte odkaz na verejné súbory (na Linuxe): 
    chmod -R 775 storage bootstrap/cache
php artisan storage:link
  7. Spustite aplikáciu (php artisan serve) a otvorte http://localhost:8000.

Inicializácia databázy

Aplikácia vyžaduje bežiaci PostgreSQL server (predvolene na 127.0.0.1:5432). Používateľ a databáza musia zodpovedať hodnotám DB_USERNAME, DB_PASSWORD a DB_DATABASE v súbore .env.

  1. Vytvorte používateľa a prázdnu databázu (heslo nahraďte vlastným a rovnaké uveďte v .env): 
    sudo -u postgres psql -c "CREATE USER iis WITH PASSWORD '<heslo>';"
sudo -u postgres psql -c "CREATE DATABASE iis OWNER iis;"
  2. Z koreňového adresára rozbaleného archívu (tam, kde je priečinok database/) spustite skripty v tomto poradí: 
    psql -h 127.0.0.1 -U iis -d iis -f database/schema.sql
psql -h 127.0.0.1 -U iis -d iis -f database/data.sql

Skript schema.sql vytvorí všetky tabuľky, primárne a cudzie kľúče aj integritné obmedzenia (pri opakovanom spustení tabuľky najprv zmaže). Skript data.sql naplní databázu testovacími používateľmi všetkých rolí, miestami, kategóriami a udalosťami a zosynchronizuje sekvencie identifikátorov. Schéma sa nevytvára Laravel migráciami, preto nespúšťajte php artisan migrate.

Nasadenie na produkčný server

Produkčná verzia aplikácie beží na cloudovej platforme Render.com (región Frankfurt) ako Docker kontajner postavený zo súboru information_system/Dockerfile, ktorý je prepojený so spravovanou inštanciou PostgreSQL 18.

Známé problémy

Kvôli dočasnému súborovému systému bezplatného hostingu Render.com sa dynamicky nahraté fotografie pri uspaní alebo reštarte kontajnera resetujú.
