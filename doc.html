Instalace

Softwarové požadavky

  • PHP: verze 8.4 nebo vyšší (s povolenými rozšířeními pdo, pdo_pgsql, zip, mbstring, openssl, tokenizer, xml, ctype)
  • Správce PHP balíčků: Composer 2.x
  • Node.js a npm: Node.js verze 22+ a npm (pro sestavení frontendových assetů přes Vite)
  • Databázový server: PostgreSQL 18 (kompatibilní s PostgreSQL 16+)
  • Použité frameworky a knihovny: Laravel 13, Inertia.js, React 19, Tailwind CSS, Vite (alternativně lze aplikaci spustit přímo v kontejneru pomocí přiloženého Dockerfile)

Lokální instalace a konfigurace

  1. Rozbalte odevzdaný archiv. Zdrojové kódy webové aplikace se nacházejí ve složce information_system/ a databázové skripty ve složce database/.
  2. Přejděte do adresáře aplikace a nainstalujte závislosti: 
    cd information_system
composer install --optimize-autoloader
npm install && npm run build
  3. Zkopírujte konfigurační soubor .env.example na .env a vygenerujte aplikační klíč: 
    cp .env.example .env
php artisan key:generate
  4. V souboru .env nastavte připojení k PostgreSQL databázi a URL aplikace: 
    APP_ENV=production
APP_URL=https://iis-project-ek26.onrender.com

DB_CONNECTION=pgsql
DB_HOST=<adresa_databazoveho_serveru>
DB_PORT=5432
DB_DATABASE=<nazev_databaze>
DB_USERNAME=<uzivatel>
DB_PASSWORD=<heslo>
  5. Nastavte práva pro zápis do adresářů storage/ a bootstrap/cache/ (na Linuxu chmod -R 775 storage bootstrap/cache).

Inicializace databáze

Databázové schéma a ukázková data jsou uložena ve složce database/. Inicializaci provedete spuštěním skriptů v následujícím pořadí přes nástroj psql (nebo v grafickém klientovi jako DBeaver/DataGrip):

psql -h <host> -U <uzivatel> -d <databaze> -f database/schema.sql
psql -h <host> -U <uzivatel> -d <databaze> -f database/data.sql

Skript schema.sql vytvoří všechny tabulky, primární a cizí klíče i integritní omezení. Skript data.sql naplní databázi testovacími uživateli všech rolí, místy, kategoriemi a událostmi a zosynchronizuje sekvence identifikátorů.

Nasazení na produkční server

Produkční verze aplikace běží na cloudové platformě Render.com (region Frankfurt) jako Docker kontejner postavený ze souboru information_system/Dockerfile (obraz php:8.4-cli s Node.js 22), který je propojen se spravovanou instancí PostgreSQL 18. Při spuštění kontejneru se cachuje konfigurace i routy (php artisan config:cache, php artisan route:cache) a spouští se vestavěný HTTP server na přiděleném portu. Na školním serveru eva.fit.vutbr.cz (~/WWW/IIS/index.html) je umístěna přesměrovací stránka odkazující na živou aplikaci.
